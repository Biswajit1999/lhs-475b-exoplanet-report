# Data source

All files are real reduced data products from Zenodo record
**7925111**, "Products and Models for 'A JWST transmission spectrum of
the nearby Earth-sized exoplanet LHS 475 b'" (Lustig-Yaeger & Fu et al.
2023, *Nature Astronomy*, 7, pp.1317-1328), downloaded
2026-08-11 from <https://zenodo.org/records/7925111>, archive
`LHS47b_Zenodo_Files.zip`.

- `nirspec_transmission_spectrum_LR.txt` (source:
  `2_Transmission_Spectra/transit_spectrum_LR_firefly_ecsv.txt`) — the
  real co-added JWST NIRSpec/G395H transmission spectrum from two real
  transit observations (JWST program GO 1981), reduced with the FIREFLy
  pipeline and binned to 56 real low-resolution wavelength points
  spanning 2.83-5.17 microns. Columns: wavelength (microns), wavelength
  bin full width, transit depth (Rp/Rs)^2, transit depth uncertainty.
- `model_pure_methane.txt`, `model_1x_solar_hydrogen_rich.txt`,
  `model_clear_venuslike.txt`, `model_pure_co2.txt` (source: files in
  `3_Models/`) — real published PICASO/CHIMERA forward-model
  transmission spectra for candidate LHS 475 b atmospheres, generated by
  S.E. Moran for the original paper and offset to the real measured
  transit depth, each pre-sampled onto the same 56-point wavelength grid
  as the data (no interpolation needed).

No numeric values were altered; files were renamed only for clarity.
The original archive also contains individual white-light curves, two
higher-resolution spectra from other reduction pipelines (Eureka!,
Tiberius), and additional atmosphere models (10x, 100x, 1000x solar,
water, Earth-like, Mars-like, hazy/cloudy Titan-like) not included here
to keep this repository small — see the Zenodo record directly for
those.
